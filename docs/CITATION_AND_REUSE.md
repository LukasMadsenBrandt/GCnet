# Citation And Reuse

This project uses the MIT License. That keeps the pipeline easy for the
scientific community to inspect, reuse, adapt, and build on. The license itself
requires users to keep the copyright and license notice with copies of the
software, but it does not legally require citation or co-authorship.

For scientific work, please cite this repository if you use the pipeline,
configuration structure, analysis code, or generated outputs in a publication,
preprint, thesis, poster, or report. The repository includes `CITATION.cff` so
GitHub and citation tools can show citation metadata directly.

## Authorship Expectation

Routine use of the software should normally be acknowledged through citation.
Co-authorship is not automatic just because the pipeline was used.

Co-authorship or collaboration is reasonable to discuss when the project
contributes substantially to the scientific work, for example:

- adapting or validating the pipeline for a new biological system;
- designing the analysis strategy for a study;
- running or optimizing large analyses that shape the manuscript conclusions;
- interpreting candidate genes, networks, or consensus results;
- developing new pipeline stages or methods for the study.

This keeps the repository open while still making the scholarly expectation
clear: cite the tool for ordinary use, and contact the author when the work
depends on substantial scientific or technical contribution.
