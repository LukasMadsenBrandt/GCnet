## 🧬 KRT85 Edge Case

While the filtered gene list contains 2311 genes, GC analysis is effectively conducted on **2310 genes**.  
This is due to **KRT85**, which has a single nonzero value (all other values zero) and thus passes initial filtering, but results in infeasible GC tests (all p-values NaN) due to statsmodels’ requirements for variance in time series data.  
This caveat is now documented in the README.
