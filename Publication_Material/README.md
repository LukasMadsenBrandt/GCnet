# Publication Material

This folder collects the manuscript figures and supplementary files in one place for GitHub readers. The figures are SVG files, so they can be opened directly in GitHub or in a browser and zoomed without loss of detail.

## Main Manuscript Figures

| Manuscript figure | Files | Figure statistics and interaction |
| --- | --- | --- |
| Fig. 1, ZEB2 expression time series examples | [ZEB2-RIC1 SVG](Figure_1/ZEB2_RIC1.svg), [ZEB2-RPL8 SVG](Figure_1/ZEB2_RPL8.svg) | Hover over points in the time series to inspect raw sample expression values and the derived day-level value from the seven raw values for that day. |
| Fig. 2, local neighborhoods of MECP2 and ZEB2 | [MECP2 SVG](Figure_2/MECP2_neighborhood.svg), [ZEB2 SVG](Figure_2/ZEB2_neighborhood.svg) | MECP2 has in-degree 3 and out-degree 1. ZEB2 has 4 in-neighbors and 5 out-neighbors. Edges can be inspected by hovering in the SVG. |
| Fig. 3, enlarged MECP2 neighborhood | [SVG](Figure_3/MECP2_enlarged_neighborhood.svg) | The induced network contains 138 genes and 156 edges. MECP2 is incident to 137 of these edges: MECP2 causes 53 genes and is caused by 84 genes. Edge hover shows the exact directed relationship; gene hover highlights outgoing edges where supported by the SVG viewer. |
| Fig. 4, enlarged ZEB2 neighborhood | [SVG](Figure_4/ZEB2_enlarged_neighborhood.svg) | The induced network contains 173 genes and 221 edges. ZEB2 is incident to 172 of these edges: ZEB2 causes 99 genes and is caused by 73 genes. Edge hover shows the exact directed relationship; gene hover highlights outgoing edges where supported by the SVG viewer. |
